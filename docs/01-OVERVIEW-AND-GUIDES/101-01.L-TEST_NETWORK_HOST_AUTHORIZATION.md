# 101: Test Network host authorization

Use this path only for a real registration into an isolated Test Network host.
It is not production-network adhesion and cannot select production policy.

1. A portal creates the controller wallet before application and commits the
   actor-signing JWK thumbprint.
2. Postal delivery moves one licence from `issued` to `delivered`. The VC
   contains no clear code or pepper, only a salted scrypt binding.
3. A human issuer employee adds an ML-DSA-65 `contractAgreement` proof.
4. `Organization/_transaction` carries that VC with
   `verification.resourceType=contract` on the `test-network` route.
5. GW verifies issuer, signer policy, proof, expiry, organization DID and
   identifier, controller email/key commitment and postal binding. Failure is
   terminal; it does not fall back to ICA.
6. GW persists the code binding outside client-authored claims and returns the
   canonical Offer id.
7. `Order/_batch` supplies the same clear postal code. GW recomputes the
   binding with `HOST_POSTAL_ACTIVATION_PEPPER` and assigns the exact value to
   the controller licence.
8. `Token/_exchange` consumes that code and DCR binds purpose-separated device
   keys to the original controller actor. Only then is the tenant active.

Canonical signer authorization uses live issuer/controller DID documents.
During the publication gap, `HOST_ORGANIZATION_AUTHORIZATION_SIGNERS` is a
revocable registry of exact issuer DID, employee DID (including its stable
email-hash member id), `RESPRSN` role, status and ML-DSA-65 JWK thumbprint. A
first unpublished key may instead require the portal/host HMAC attestation,
created only after the BFF unlocks the existing reviewer wallet. It supplements
but never replaces the ML-DSA-65 proof. Fabric can later own the employee,
role, key and revocation policy. Remove the bridge when DID publication is live.
It cannot run on `network`; production remains ICA-backed.

Audit evidence must show redacted VC/Offer/job/DCR identifiers and final host
readback. Never log the clear code, pepper, ID token, PIN, seed, recovery share
or private JWK members.
