Guía reproducible para el alta y despliegue de un host

Documento público en español para memoria, consultoría e integración.

1. Qué es el recolector de evidencias

El término «runner SEDIA» es informal. No es Helm ni una herramienta oficial de SEDIA. Es el recolector público scripts/collect-open-source-production-readiness-evidence.sh, invocado mediante npm run evidence:open-source-production-readiness. Ejecuta las pruebas y genera estados, logs saneados, resumen y manifiesto con hashes.

2. Flujo objetivo

Autorización del host
        ↓
HostingServiceCredential (VC JSON y VC-JWT)
        ↓
Registro gobernado en la ICA de Fabric
        ↓
Enrolamiento MSP y TLS con claves privadas locales
        ↓
Secrets de Kubernetes
        ↓
helm upgrade --install gdc-host
        ↓
Peer + CouchDB + GW CORE + PostgreSQL + IPFS + CCAAS
        ↓
Canales, escritura, lectura, denegación y reinicio

3. Evidencia ejecutada

  • CA del espacio de datos local con Root e Issuer desechables.
  • ICA del espacio de datos y Host VC JSON/VC-JWT sin PDF para un host preautorizado.
  • ICA de Fabric, certificados MSP/TLS, Host1MSP, Host2MSP, canales y chaincodes.
  • GW CORE, PostgreSQL e IPFS con escritura, lectura y recuperación tras reinicio.
  • Instalación real de peer Host1MSP, CouchDB, GW CORE, PostgreSQL, IPFS y nueve runtimes CCAAS mediante kind y Helm.
  • Unión del peer Kubernetes a los canales locales, instalación y aprobación de los paquetes CCAAS exactos.
  • GW dirigido al peer Kubernetes, con persistencia y nueva capacidad de endoso tras reiniciar GW, peer y CCAAS.
  • Acceso consentido y controles negativos de acceso no autorizado.
Separación comprobada: Docker mantiene la ICA de Fabric, el orderer y un peer de referencia como red externa. El peer desplegado por Helm se une a esa red y el GW endosa exclusivamente mediante ese peer Kubernetes; la ruta al peer Docker solo se usa para gossip/bootstrap.

4. Qué hace realmente la puerta Kubernetes

La prueba ya no se limita a helm template. Crea un clúster kind aislado, namespace y Secrets; carga la imagen aprobada; ejecuta helm upgrade --install; espera el rollout; realiza operaciones E2E; comprueba canales y CouchDB; consulta PostgreSQL e IPFS dentro de los pods; instala y aprueba los nueve paquetes CCAAS en el peer Kubernetes; ejecuta Consent y SMART mediante ese peer; reinicia GW, peer y CCAAS y comprueba la recuperación. helm template permanece como comprobación estática complementaria.

5. Promoción del mismo chart

EntornoChartDiferencias
local-networkgdc-hostImágenes y autoridades locales, DNS .localhost y StorageClass de kind.
test-networkgdc-hostDigests publicados, autoridades de staging, DNS/TLS y almacenamiento cloud.
Produccióngdc-hostHost VC y certificados nuevos, digests aprobados, KMS y values del proveedor.

No se reutilizan MSP, TLS, claves, Secrets, grants ni credenciales verificables entre entornos. Se reutilizan el chart, su estructura de configuración y las versiones o digests aprobados.

6. Responsabilidad de Helm

Helm no crea la red Fabric, no actúa como administrador de ninguna ICA y no decide qué MSP entra en los canales. Antes de instalar un host autónomo deben existir la autorización, el grant de enrolamiento, el material MSP/TLS generado por el host, la incorporación gobernada a los canales y los Secrets Kubernetes. La reconciliación privilegiada se ejecuta por la autoridad.

7. Datos requeridos al proveedor

  • Versión de Kubernetes, namespace, StorageClass e IngressClass.
  • DNS, TLS, reglas de red y registro de imágenes.
  • PVC, backups, restauración y observabilidad.
  • Gestor de secretos y custodia externa del KEK.
  • Valores no secretos del release y canal seguro para grants y Secrets.

8. Criterio de presentación

La memoria puede afirmar que la red Fabric local y el despliegue Kubernetes con peer, CouchDB, GW CORE, PostgreSQL, IPFS y CCAAS se han probado de forma reproducible, incluido el lifecycle CCAAS y el E2E del GW contra el peer Kubernetes. La promoción a otra red conserva el chart, pero exige nuevas credenciales, Secrets, digests, values y reconciliación gobernada.
